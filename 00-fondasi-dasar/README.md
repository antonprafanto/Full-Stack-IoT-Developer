## 🎯 Capaian Pembelajaran Fase 0:
1. ✅ Memahami fisika kelistrikan secara intuitif tanpa takut kesetrum atau merusak laptop.
2. ✅ Mengetahui cara merangkai komponen di breadboard tanpa korsleting (*short circuit*).
3. ✅ Mampu menulis logika program C++ embedded yang hemat memori dan bebas kebocoran RAM.
4. ✅ Mampu menulis skrip Python untuk memproses paket data JSON telemetri.
5. ✅ Berhasil menjalankan sirkuit virtual dan Serial Monitor di **Wokwi Simulator**.

## ⚡ Fase 0: Fondasi Listrik Ramah Pemula, Logika Komponen & Pemrograman Inti (Minggu 1-2)

> **Tujuan Pembelajaran:** Membangun intuisi kelistrikan dari nol mutlak tanpa takut korslet, memahami cara kerja chip silikon, prinsip dasar sirkuit (*Common Ground*), serta menguasai logika pemrograman C++ dan Python secara bertahap.

### 0.0 Pengantar Konseptual: "Bagaimana Kode Masuk ke Chip Silikon?"
- [ ] **Komputer vs Mikrokontroler:** Mengapa ESP32 tidak butuh Windows/Linux dan langsung mengeksekusi biner dari memori Flash (*Bare-Metal Execution*).
- [ ] **Alur Kompilasi & Flashing:**
  - Menulis Kode C++ (`.cpp` / `.ino`) $\rightarrow$ Diterjemahkan oleh Kompiler (*xtensa-gcc*) menjadi biner mesin (`.bin`).
  - File biner dikirim melalui kabel USB lewat chip konverter USB-to-UART (CP2102 / CH340) menuju memori SPI Flash ESP32.
- [ ] **Deteksi Port USB (COM Port) di Windows:** Mengatasi driver CH340/CP2102 yang belum terpasang di Device Manager.
- [ ] **Fungsi Tombol Fisik `EN` (Reset) dan `BOOT` (GPIO 0):** Mengapa tombol BOOT harus ditekan saat upload jika sirkuit auto-reset USB mengalami kegagalan handshake.

### 0.1 Dasar Listrik Intuitif (Analogi Aliran Air)
- [ ] **Tegangan ($V$ - Volt):** Tekanan air dari tandon/pompa (Beda potensial listrik yang mendorong elektron).
- [ ] **Arus ($I$ - Ampere):** Debit/volume air yang mengalir per detik melalui pipa.
- [ ] **Hambatan ($R$ - Ohm):** Penyempitan pipa/keran yang menahan laju aliran air.
- [ ] **Daya Listrik ($P$ - Watt):** Total energi yang dihasilkan ($P = V \times I$).
- [ ] **Hukum Ohm ($V = I \times R$):** Cara menghitung resistor pengaman agar LED tidak meledak/terbakar ($R = \frac{V_{\text{sumber}} - V_{\text{LED}}}{I_{\text{LED}}}$).
- [ ] **Arus DC (Direct Current) vs AC (Alternating Current):** Mengapa mikrokontroler menggunakan DC 3.3V/5V sedangkan listrik rumah tangga AC 220V.

### 0.2 Anatomi Breadboard & Komponen Fisik (Anti-Korslet)
- [ ] **Cara Kerja Breadboard:**
  - Memahami jalur plat tembaga di dalam breadboard: *Power Rails* (terhubung horizontal $+/-$) vs *Terminal Strips* (terhubung vertikal kolom A-B-C-D-E dan F-G-H-I-J).
  - Kesalahan fatal pemula: Menancapkan kedua kaki komponen di kolom vertikal yang sama (menyebabkan *short circuit*).
- [ ] **Mengenal Komponen & Cara Menentukan Polaritas (Positif/Negatif):**
  - *LED (Light Emitting Diode):* Kaki panjang = Anoda ($+$), Kaki pendek / sisi pipih = Katoda ($-$).
  - *Resistor:* Membaca gelang warna resistor ($220\Omega, 1k\Omega, 10k\Omega$) & mengukur dengan Multimeter.
  - *Kapasitor:* Kapasitor Elektrolit (ada garis tanda negatif $-$) vs Kapasitor Keramik (bebas bolak-balik).
  - *Dioda & Transistor:* Garis perak pada dioda (katoda), kaki transistor BJT (Collector, Base, Emitter) dan MOSFET (Gate, Drain, Source).
- [ ] **Kabel Jumper:** Membedakan kabel *Male-to-Male (M-M)*, *Male-to-Female (M-F)*, dan *Female-to-Female (F-F)*.

### 0.3 Logika Sirkuit Dasar & Fenomena Penting IoT
- [ ] **Prinsip Mutlak Common Ground (GND Sharing):**
  - Mengapa semua sensor, catu daya eksternal, dan ESP32 **WAJIB** menghubungkan pin GND bersama? (Tanpa GND bersama, tegangan tidak memiliki titik acuan 0V sehingga pembacaan sensor menghasilkan nilai acak/rusak).
- [ ] **Rangkaian Pembagi Tegangan (*Voltage Divider*):**
  - Rumus: $V_{\text{out}} = V_{\text{in}} \times \frac{R_2}{R_1 + R_2}$.
  - Mengapa sensor analog (seperti LDR / Termistor) wajib menggunakan rangkaian pembagi tegangan agar bisa dibaca oleh pin mikrokontroler.
- [ ] **Fenomena "Floating Pin" & Solusi Resistor Pull-up / Pull-down:**
  - Mengapa pin input yang tidak diberi resistor nilainya berubah-ubah acak antara 0 dan 1 (menangkap interferensi gelombang radio seperti antena).
  - Skema Pull-up (default HIGH / 1) vs Pull-down (default LOW / 0).
- [ ] **Transistor / Relay sebagai Sakelar Elektronik:**
  - Mengapa pin ESP32 (maksimal 3.3V / 12mA) tidak boleh langsung dihubungkan ke motor DC atau lampu 220V.
  - Menggunakan sinyal kecil 3.3V dari ESP32 untuk memicu transistor / relay yang mengalirkan daya besar.
- [ ] **Pengenalan Alat Ukur:** Penggunaan Multimeter Digital (mengukur tegangan DC, kontinuitas jalur bunyi 'beep', resistansi) dan USB Logic Analyzer untuk debugging bus.

### 0.4 Pemrograman C/C++ dari Nol (Khusus Embedded & Mikrokontroler)
- [ ] **Struktur Dasar Program Embedded:** Perbedaan `setup()` (dijalankan 1 kali saat dinyalakan) dan `loop()` (berputar terus menerus selamanya).
- [ ] **Variabel & Tipe Data Fixed-Width:** `bool`, `char`, `uint8_t` (0-255), `int16_t`, `int32_t`, `float`, `double`.
- [ ] **Scope Variabel (Lokal vs Global):** Variabel global tersimpan permanen di SRAM, sedangkan variabel lokal di dalam fungsi akan hilang setelah fungsi selesai dieksekusi.
- [ ] **Logika Percabangan & Perulangan:** `if`, `else if`, `else`, `switch-case`, `for`, `while`.
- [ ] **Fungsi (Functions):** Parameter, Return Value, Prototype functions.
- [ ] **Array & Buffer:** Menyimpan kumpulan data sensor (`int sensorReadings[10]`).
- [ ] **Pointer & Referensi Ramah Pemula:** Konsep alamat memori (`&`) dan pointer (`*`) dianalogikan sebagai nomor rumah dan isi rumah.
- [ ] **Bitwise Logic Dasar:** Mengontrol status pin register dengan operator AND (`&`), OR (`|`), XOR (`^`), dan Bit Shift (`<<`, `>>`).

### 0.5 Pemrograman Python dari Nol (Khusus Gateway & Cloud Ingestion)
- [ ] Variabel, Tipe Data (String, Integer, Float, Boolean).
- [ ] Struktur Data: List `[]`, Dictionary `{}` (kunci-nilai JSON), Tuples `()`.
- [ ] Fungsi, Modul, dan Virtual Environment (`venv` / `uv`).
- [ ] Dasar Pemrograman Asinkron (`asyncio`, `await`) dan serialisasi data (`json`, `struct`).

### 0.6 Setup Lingkungan Belajar (Tools & Simulator Virtual)
- [ ] Instalasi **VS Code** + Ekstensi **PlatformIO IDE** (Manajemen proyek, library, dan board mikrokontroler otomatis).
- [ ] Praktik Langsung Tanpa Beli Alat: **Wokwi Simulator** (Membuat rangkaian ESP32, resistor, LED, push button, dan sensor langsung di browser).
- [ ] Dasar Version Control: **Git & GitHub** untuk menyimpan kode latihan.

## 🔌 Fase 1: Langkah Demi Langkah Mikrokontroler ESP32 — Dari Blink ke FreeRTOS (Minggu 3-6)

> **Tujuan Pembelajaran:** Memahami anatomi pinout ESP32, menaklukkan input/output digital, analog, komunikasi serial, sensor bus, troubleshooting error pemula, hingga multi-tasking FreeRTOS tingkat lanjut.

```
┌────────────────────────────────────────────────────────────────────────┐
│                   ESP32 NATIVE DUAL-CORE RTOS TOPOLOGY                 │
│                                                                        │

│  │  [ Task Wi-Fi / Thread ] ◄── Event Group ──► [ Task mTLS ]  │       │
│  │  [ Task Web Provision  ] ◄── Queue ───────► [ Task OTA ]    │       │
│  └───────────────────────────┬─────────────────────────────────┘       │

│  └─────────────────────── APP CPU (Core 1) ────────────────────┘       │
│                              │                                         │
│  ┌───────────────────────────▼──────────────────────────────────────┐  │
```

### 1.1 Anatomi Board ESP32 DevKit & Aturan Pinout Aman
- [ ] Mengetahui fungsi pin ESP32 (30/38 pin):
  - **Pin Aman untuk Input/Output:** GPIO 4, 16, 17, 18, 19, 21, 22, 23, 25, 26, 27, 32, 33.
  - **Pin Input-Only (Tidak bisa jadi Output):** GPIO 34, 35, 36, 39 (Sangat cocok untuk sensor analog).
  - **Pin Berbahaya / Strapping Pins:** GPIO 0, 2, 12, 15 (Jangan pasang beban saat booting agar ESP32 bisa menyala normal).
  - **Aturan ADC2 & Wi-Fi:** ADC2 tidak bisa membaca analog saat Wi-Fi aktif, gunakan pin pada ADC1 (GPIO 32 - 39).

### 1.2 Proyek 1: Digital Output (Kendali LED & Aktuator)
- [ ] `pinMode(pin, OUTPUT)` dan `digitalWrite(pin, HIGH / LOW)`.
- [ ] Pola Running LED, LED Berkedip Bergantian.
- [ ] Konsep **Active High** (Menyala saat diberi tegangan 3.3V/HIGH) vs **Active Low** (Menyala saat dihubungkan ke Ground/LOW — sering digunakan pada modul relay).

### 1.3 Proyek 2: Digital Input & Tombol Tekan (Push Button)
- [ ] `pinMode(pin, INPUT_PULLUP)` (Memanfaatkan resistor pull-up internal ESP32 tanpa pasang resistor eksternal).
- [ ] `digitalRead(pin)`: Membaca status tombol.
- [ ] **Logika Toggle Switch:** Sekali tekan menyala, tekan lagi mati (Menyimpan status `bool ledState`).
- [ ] **Menangani Mechanical Button Bouncing:** Mengapa tombol fisik memicu 10x sinyal dalam 5ms karena getaran pegas mekanik, dan cara mengatasinya dengan teknik *Software Debouncing*.

### 1.4 Proyek 3: Serial Communication & Debugging
- [ ] Inisialisasi `Serial.begin(115200)`.
- [ ] Mencetak data variabel dan teks ke Serial Monitor (`Serial.print`, `Serial.println`, `Serial.printf`).
- [ ] Mengapa muncul karakter aneh/rusak? Memahami ketidaksesuaian Baud Rate antara kode dan Serial Monitor.
- [ ] Membaca input dari Serial Monitor (`Serial.readString()`).

### 1.5 Proyek 4: Sinyal Analog (ADC & PWM)
- [ ] **Analog Input (ADC):**
  - `analogRead(pin)`: Mengonversi tegangan fisik $0\text{V} - 3.3\text{V}$ menjadi nilai integer $0 - 4095$ (Resolusi 12-Bit).
  - Membaca Potensiometer dan Sensor Cahaya LDR.
  - Pemetaan Rentang Angka dengan fungsi `map(val, 0, 4095, 0, 100)`.
- [ ] **Analog Output / PWM (Pulse Width Modulation):**
  - Mengapa mikrokontroler tidak bisa mengeluarkan voltase analog murni? Konsep *Duty Cycle* (menghidup-matikan pin dengan frekuensi ribuan kali per detik).
  - Mengatur kecerahan lampu LED (*Fading Effect*) menggunakan fungsi PWM ESP32 (`ledcAttachPin`, `ledcWrite`).
  - Mengontrol sudut putar Motor Servo SG90 ($0^\circ - 180^\circ$).

### 1.6 Proyek 5: Mengatasi Jebakan `delay()` dengan `millis()` Non-Blocking
- [ ] Mengapa fungsi `delay(5000)` adalah musuh terbesar sistem IoT? (Membuat CPU diam membeku sehingga tombol tidak responsif dan koneksi jaringan terputus).
- [ ] **Teknik Timer Stopwatch `millis()` (Blink Without Delay):**
  - Konsep mencatat waktu sebelumnya (`previousMillis`) dan membandingkannya dengan waktu sekarang (`currentMillis`).
  - Menjalankan 3 tugas sekaligus dengan interval berbeda tanpa macet (misal: LED berkedip tiap 500ms, baca sensor tiap 2000ms, dengarkan tombol tiap 10ms).

### 1.7 Proyek 6: Protokol Bus Sensor Hardware (I2C, SPI, 1-Wire)
- [ ] **Protokol I2C (Inter-Integrated Circuit):**
  - Mengapa butuh I2C? Menghemat pin! 100+ sensor bisa dihubungkan hanya dengan 2 kabel (SDA & SCL).
  - Konsep Alamat Heksadesimal I2C (*I2C Address Scanner*).
  - Menampilkan teks, angka sensor, dan grafik di **Layar OLED 0.96" SSD1306**.
  - Membaca Sensor Suhu, Kelembaban & Tekanan Presisi tinggi **BME280 / BMP280**.
- [ ] **Protokol SPI (Serial Peripheral Interface):** Jalur MOSI, MISO, SCK, CS (Kecepatan tinggi untuk modul MicroSD Card Data Logging).
- [ ] **Protokol 1-Wire:** Membaca sensor suhu anti-air industri **DS18B20**.

### 1.8 Jembatan Menuju Mahir: FreeRTOS, ESP-IDF & Kehandalan Firmware
- [ ] Mengapa butuh Real-Time Operating System (FreeRTOS) saat proyek bertambah besar?
- [ ] Membuat Task Terpisah pada Core 0 dan Core 1 (`xTaskCreatePinnedToCore`).
- [ ] Komunikasi aman antar-Task menggunakan FreeRTOS Queues dan Mutex.
- [ ] Arsitektur Finite State Machine (FSM): Membagi alur sistem ke dalam state yang jelas tanpa *spaghetti code*.
- [ ] Pencegahan Sistem Hang: **Hardware & Task Watchdog Timer (WDT)** dan penanganan *Brownout Voltage Dip*.
- [ ] Profiling Memori Heap (`esp_get_free_heap_size()`) dan teknik *Wear-Leveling* pada LittleFS Flash Storage.

### 1.9 Katalog Pemecahan Masalah Pemula (Beginner Troubleshooting Compendium)
- [ ] **Error: "Failed to connect to ESP32: Timed out waiting for packet header"**
  - *Penyebab:* Kegagalan handshake auto-reset serial.
  - *Solusi:* Tekan dan tahan tombol `BOOT` pada ESP32 saat status di terminal menampilkan `Connecting.......`, lalu lepas setelah proses upload biner dimulai.
- [ ] **Error: "Brownout detector was triggered"**
  - *Penyebab:* Penurunan tegangan mendadak saat modul radio Wi-Fi menyala (butuh arus ~300mA).
  - *Solusi:* Ganti kabel USB yang berkualitas lebih tebal / tambahkan kapasitor elektrolit $100\mu\text{F}$ di antara pin 3.3V dan GND.
- [ ] **Error: "Guru Meditation Error: Core 1 panic'ed (LoadProhibited / StoreProhibited)"**
  - *Penyebab:* Pointer bernilai NULL atau index array melewati batas memori (*Buffer Overflow*).
  - *Solusi:* Periksa inisialisasi pointer dan ukuran buffer array.
- [ ] **Masalah: ESP32 tidak bisa terhubung ke Wi-Fi rumah**
  - *Penyebab:* Router menggunakan frekuensi 5 GHz murni.
  - *Solusi:* ESP32 hanya mendukung frekuensi **2.4 GHz**. Pastikan SSID 2.4 GHz diaktifkan pada router.
- [ ] **Masalah: Pembacaan Analog ADC selalu bernilai 4095**
  - *Penyebab:* Pin tidak terhubung ke sensor (*floating*) atau menggunakan pin ADC2 saat Wi-Fi aktif.
  - *Solusi:* Pindahkan sensor ke pin kelompok ADC1 (GPIO 32, 33, 34, 35, 36, 39).

## 🛠️ Fase 2: Desain Perangkat Keras, Skematik, Multi-Layer PCB & DFM (Minggu 7-8)

> **Tujuan Pembelajaran:** Mampu merancang sirkuit elektronika multi-layer standar industri, menata layout PCB dengan integritas sinyal tinggi, dan menyiapkan file manufaktur massal.

### 2.1 Desain Skematik Profesional (KiCad 8.x)
- [ ] Hierarchical Schematic Design (Sheet terpisah: Power, MCU, Radio, Analog Sensors, Digital Buses).
- [ ] **Rangkaian Catu Daya Efisiensi Tinggi:**
  - Input Proteksi: Reverse Polarity Protection (P-MOSFET), Resettable Polyfuse (PTC), TVS Diode.
  - Step-Down Buck Converter (MP2315 / TPS62130) dengan ripple <20mV.
  - Ultra-Low Quiescent Current LDO (AP2112K / TPS7A02) dengan $I_q < 25\text{nA}$ untuk perangkat baterai.
- [ ] **Signal Conditioning & Isolation:**
  - Optocoupler Isolation (PC817 / 6N137) untuk relay dan aktuator tegangan tinggi.
  - Logic Level Shifter Bidirectional (TXS0108E / BSS138) 3.3V $\leftrightarrow$ 5V.

### 2.2 Desain Layout PCB 4-Layer & Signal Integrity
- [ ] **Stackup 4-Layer:** Layer 1 (Signal) - Layer 2 (GND Solid Plane) - Layer 3 (Power Plane) - Layer 4 (Signal/GND).
- [ ] **Integritas Sinyal & EMI/EMC:**
  - Return Current Path: Memastikan ground return path tidak terpotong oleh split plane.
  - Impedansi Terkontrol (*Controlled Impedance Trace*) $50\Omega$ untuk jalur antena RF.
  - Area Keep-Out di bawah antena PCB onboard ESP32.
- [ ] Thermal Relief & Copper Pours untuk pembuangan panas komponen daya.

### 2.3 DFM (Design for Manufacturing) & DFA (Design for Assembly)
- [ ] Penempatan Fiducial Marks (3 titik optik pada sudut PCB untuk mesin Pick-and-Place SMT).
- [ ] Test Points (TP): Menempatkan titik kontak jarum Pogo-Pin pada rel daya, GPIO, UART TX/RX, dan EN/BOOT pin.
- [ ] Export File Produksi: Gerber RS-274X, Excellon Drill, BOM (Bill of Materials), CPL / Centroid (Pick-and-Place).

### 3.1 Teknik Pemutusan Daya Nano-Power (Power-Gating)
- [ ] Mengapa Deep Sleep ESP32 (~10-15$\mu$A) masih terlalu boros untuk target 10 tahun?
- [ ] Menerapkan **Hardware Nano-Timer (Texas Instruments TPL5110 / TPL5010)**:
  - Memutus daya fisik mikrokontroler sebesar 100% saat tidak bertugas.
  - Arus standby sirkuit turun drastis menjadi **$35\text{ nA}$** (Nanoampere).

### 3.2 Kimia Baterai Industri & Perhitungan Umur Baterai
- [ ] Perbandingan Kimia Baterai:
  - Baterai Sekunder (Rechargeable): LiFePO4 (Tahan suhu tinggi $-20^\circ\text{C} - 60^\circ\text{C}$, 2000+ cycles) vs Li-ion 18650.
  - Baterai Primer (Non-Rechargeable): **Lithium Thionyl Chloride ($Li-SOCl_2$ ER14505/ER34615)** dengan kepadatan energi tertinggi dan self-discharge <1% per tahun.
- [ ] **Kalkulasi Matematis Umur Baterai:**
  $$\text{Umur (Jam)} = \frac{\text{Kapasitas Baterai (mAh)} \times \text{Derating Factor (0.85)}}{(T_{\text{active}} \times I_{\text{active}}) + (T_{\text{sleep}} \times I_{\text{sleep}})}$$

### 3.3 Pemanenan Energi (*Energy Harvesting*)
- [ ] Solar Panel MPPT (Maximum Power Point Tracking) menggunakan IC manajemen daya baterai **CN3791 / BQ25570**.
- [ ] Pemanenan Energi Alternatif: Piezoelectric (getaran mesin), Thermoelectric Generator / TEG (perbedaan suhu pipa panas).

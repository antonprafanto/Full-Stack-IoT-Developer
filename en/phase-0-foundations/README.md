# 🟧 Phase 0 — Foundations: Electricity, Code, & Tools (Modules 1–4)

🌐 **English** · [Bahasa Indonesia](../../fase-0-fondasi/README.md)

> **Phase goal:** take away the fear. By the end of this phase you are already "talking" to a chip through code, you understand why USB power is safe, and you have a set of tools that you installed one at a time, exactly when you needed them.

Work through the modules **in order**. One module = one week (6–10 hours, spread out). Click a module title to open its article.

| Week | Module | Hardware | Tools installed in this module | Status |
| :---: | :--- | :--- | :--- | :--- |
| 1 | **[Module 1 — The Big Picture of IoT & Your First Win in 10 Minutes](module-01-big-picture-iot/README.md)** | none (Wokwi in the browser) | — (just a browser and a GitHub account) | ✅ available |
| 2 | **[Module 2 — Electricity for Beginners, Breadboards, & Your First Upload to a Real ESP32](module-02-electricity-and-first-upload/README.md)** | Kit A Stage 1 (start in Wokwi if your kit hasn't arrived yet) | Arduino IDE 2 + the esp32 package, USB driver | ✅ available |
| 3 | **[Module 3 — C++ Programming for the ESP32 from Scratch](module-03-cpp-for-esp32/README.md)** | optional (every practice works without a board) | GitHub Desktop | ✅ available |
| 4 | **[Module 4 — JavaScript & Node.js from Scratch (the Language for Servers & Dashboards)](module-04-javascript-nodejs/README.md)** | none | Visual Studio Code, Node.js 24 | ✅ available |

🎉 **All Phase 0 modules are available.** Once you have finished all four, check the completion criteria below, then continue to **[Phase 1 — ESP32 Embedded](../phase-1-esp32-embedded/README.md)**, starting with [Module 5](../phase-1-esp32-embedded/module-05-gpio-and-pin-map/README.md).

## 🎯 Phase 0 completion criteria

Before moving on to Phase 1, make sure these three pieces of evidence are in your GitHub repository ([Syllabus §8](../SYLLABUS.md#8-evaluation--completion-criteria-for-each-phase)):

1. The quiz of every module (5 questions): **at least 4 correct**.
2. **Checkpoint project:** a 3-LED traffic light in C++ (Module 3) plus a statistics script and a mini server in JavaScript (Module 4).
3. **Artifacts:** code and Wokwi screenshots saved on GitHub.

## 📂 What each module folder contains

| Content | Purpose |
| :--- | :--- |
| `README.md` | The module article — start reading here. GitHub shows it automatically when you open the module folder. |
| `code/` | All the code used in the article. Modules 1–3: one folder per program, ready to copy into Wokwi or the Arduino IDE. Module 4: one complete Node.js project (`package.json` and all `.js` files), ready to open in VS Code. |
| `assets/` | The article's images, plus `SOURCES.md`, which records the source and license of every image. |

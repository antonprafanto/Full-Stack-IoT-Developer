# Sources & Image Credits — Module 20

A summary of every image in this folder. The curriculum's original diagrams are licensed **CC BY 4.0**, and their `.svg` files are included so they can be modified. The numbers, messages, and examples in the diagrams come from the author's lab for this module: backend v0.5 on a Windows laptop with the lab database, Bruno, curl, and PowerShell. The example bcrypt fingerprints, JWT wristbands, and season passes in the pictures were made just for the examples: none of them belongs to a real account or backend. All sources were accessed in October 2026.

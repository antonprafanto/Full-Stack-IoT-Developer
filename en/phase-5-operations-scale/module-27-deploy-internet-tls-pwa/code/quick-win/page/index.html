Hello from a sealed envelope

This page arrived over https://: its content was encrypted on the way, like a letter in a sealed envelope.

But the browser warned you just now, because this site's ID card (certificate) was issued by Caddy itself ("Caddy Local Authority"), not by an issuer that phones and laptops all over the world know. This is the same as setInsecure() in Module 10, seen from the browser's side.

This week we get an ID card that every browser recognizes: from Let's Encrypt, for your own domain name.

# Sources & Image Credits — Module 25

A recap of all the images in this folder. The original curriculum diagrams are licensed **CC BY 4.0**, and their `.svg` files are included so they can be edited. The diagrams follow the code of this module (backend 1.2: `src/routes/devices.ts`, `src/routes/reports.ts`, `src/services/reports.ts`, `src/services/csv.ts`, `src/services/telegram.ts`, `src/config/env.ts`; frontend 1.1: `src/map.ts`, `src/components/DeviceMap.tsx`, `src/pages/Map.tsx`; the `grafana/` folder: `grafana-user.sql`, `dashboards/system-health.json`, `alerting/silent-node.yaml`; `tools/device-simulator.js`; `edge/acl-broker`) and the behavior the author tested on a **Raspberry Pi 5 running Ubuntu 26.04 (arm64) playing the laptop**, like the Indonesian edition: Docker Engine 29 (not Docker Desktop), Grafana 13.2.4 (`grafana/grafana:13.2.4`), TimescaleDB 2.30.2, a locked Mosquitto 2.0.22, this module's backend 1.2 and frontend 1.1, Google Chrome 156. The data senders are mock programs: the simulator `f00d00000001` and the **mock Garden** `f00d000000b2` (`tools/` of this module), not a real Node 1/Node 2 and no real battery pulled out; Telegram = a **mock Bot API server** in the author's lab, not a real Telegram bot, so the message texts in the diagrams are the texts that mock server received. The alert times in the diagrams are the recordings of **two runs** in the author's lab written as ranges (🔴 simulator 5 min 46 s – 5 min 58 s, Garden 5 min 55 s – 11 min 10 s after the pull, 📴 ±17 minutes, Grafana ✅ +3 min 22 s – 4 min 26 s); the English lab's own runs fell inside the same formula. The Telegram message boxes and the report rehearsal (00:04:00 WIB) each come from one run, so the numbers of your run can shift by about a minute while staying inside the formula; times are written in WIB. The report diagram writes its two example CSV rows in the English recipe (comma, decimal point) with the values of that run, and its size (302 bytes) is what this module's `csv.ts` makes of those rows. Windows/macOS-only parts (Docker Desktop, `host.docker.internal`) were not tested by the author. The map points (around Monas, Jakarta) are **fictional**, and the laptop IP `192.168.1.10` and the sensor numbers in the diagrams are **examples**; the Map screen and the mini screens in the diagrams are **illustrations** (tiles, roads, and app colors simplified): the real screens are in the screenshots. The `⏰ … was missed` message in the report diagram uses the format of the `reports.ts` code with the example time 07:00 WIB.

The screenshots come from the author's English lab of 28 October 2026, on the same Raspberry Pi 5 with **headless Google Chrome 156 (`Chrome/156.0.8078.47`)**, driven over the DevTools protocol: `--lang=en-US`, the time zone emulated as `Asia/Jakarta` (WIB), scale 2, width 1280 px (the whole dashboard with a temporary 1280 × 1000 px window; the 375 px width = **DevTools device mode, not a real phone**), against Grafana OSS 13.2.4 (`/api/health`: version 13.2.4, commit `0e79aef9d9`) in its **default dark theme**, the TimescaleDB 2.30.2 lab database, and this module's real backend 1.2 and frontend 1.1; the data comes from the same mock senders (the simulator `f00d00000001` and the **mock Garden** `f00d000000b2`, which sends every 300 seconds, never shortened) plus the practice history from `npm run seed-history`. Grafana's data source reaches the lab database as `smarthome-db:5432` through a network alias of the lab database container. The Grafana objects (data source, `First panel`, `System Health`, the contact point, the `Silent node` rule) were made through the Grafana screens in the English lab; the **Update your password** card was shot in a fresh, throw-away Grafana 13.2.4 container (the same image and settings, removed afterwards; the card was not submitted), because the lab Grafana's password had already been changed. The mock Telegram server is reached by Grafana only through two test-only lab options that are not part of the reader's command (a CA bundle and `SSL_CERT_FILE`); it uses a fake bot token and a fake `chat_id` (`777000111`, shown as it is), so there is no screenshot of the Telegram app, and no picture shows the token. The Map tiles are real OpenStreetMap tiles, loaded sparingly (12 tiles, no prefetch). The CSV report is **not opened in Excel or LibreOffice** (no spreadsheet on the author's machine): its content is shown as terminal text (`cat`, `xxd`). No password, cookie, key, token, machine path, or real IP address appears in any picture, and no lab port or lab container name either (headless Chrome has no address bar). The sensor numbers and times in the screenshots are examples; the times on the Grafana and Map screens are WIB, in `csv-report` the backend log times are WIB (the lab backend ran with `TZ=Asia/Jakarta`) and the mock server's time is UTC, both noted in the picture. A real phone, a real Node 2 with its battery pulled out, the real Telegram app, Excel/LibreOffice, and Docker Desktop were **not** tested by the author. All sources accessed October 2026.

Mini Smart Home

A small note about Node 1, the device in the living room.

Jump to: Sensors · Actuators · Example readings

Sensors on Node 1

  • DHT22: air temperature and humidity
  • LDR: light
  • Capacitive soil sensor: soil moisture
  • PIR: motion
  • HC-SR04: the water height in the tank

Actuators on Node 1

  • Lamp relay
  • Fan relay
  • Pump (through an IRLZ44N MOSFET)
  • SG90 curtain servo
  • Passive buzzer

The order for powering up the Node 1 workbench:

  1. Plug the USB cable into the ESP32 board.
  2. Only then turn on the MB102 (the relays need 5 V from the MB102).

# Sources & Image Credits — Module 22

A recap of all the images in this folder. The original curriculum diagrams are licensed **CC BY 4.0**, and their `.svg` files are included so they can be edited. The diagrams follow the code and behavior of backend v1.0 from Module 21, retested by the author (the `access` and `session` cookies, the `204` *preflight* answer from @fastify/cors 11.3.1, `401`, `POST /auth/refresh`), the Node 1 page from Module 10 (`networking.cpp` lines 80–97), and the dashboard v0.1 design of this module. The sensor numbers, device names, and screen contents in the diagrams are **examples**: the real dashboard screens are in the screenshots. The screenshots come from the author's English lab of 24 October 2026: headless Microsoft Edge 155 (Edg/155.0.4283.62) in light mode, with the time zone emulated as Asia/Jakarta; the English backend v1.0 with its TimescaleDB database; **a mock MQTT broker instead of Mosquitto**, checking the same password file and access list; and lab simulators that send **fixed numbers** for Node 1 and Node 2 (the practice device `f00d00000001` is sent by `tools/device-simulator.js` with random numbers). The accounts are the Module 20 ones, `admin@home.test` (Home Admin) and `viewer@home.test` (Home Guest); no password appears in any picture (password fields show dots only). All sources accessed October 2026.

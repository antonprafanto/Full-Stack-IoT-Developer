# Sources & Image Credits — Module 23

A recap of all the images in this folder. The original curriculum diagrams are licensed **CC BY 4.0**, and their `.svg` files are included so they can be edited. The diagrams follow the dashboard v0.2 code of this module (`src/socket.ts`, `src/store.ts`, `src/time.ts`, `LiveChart.tsx`, `Gauge.tsx`, `ConnectionBadge.tsx`, `Badge.tsx`, `LastSeen.tsx`, `DeviceDetails.tsx`) and the behavior of backend v1.0 from Module 21, retested by the author: the Socket.IO events `follow`, `telemetry`, and `status`; the disconnect reasons `io server disconnect`, `io client disconnect`, and `transport close`; `GET /devices/:id/readings` with and without `bucket`; and phone mode through the laptop's Wi-Fi IP address. The sensor numbers, times, device names, and the laptop IP `192.168.1.10` in the diagrams are **examples**: the real dashboard screens are in the screenshots. The screenshots come from the author's English lab of 25 October 2026: headless Microsoft Edge 156 (Edg/156.0.4314.42) driven over the DevTools protocol, with the time zone emulated as Asia/Jakarta and the color scheme emulated (`prefers-color-scheme`, light unless the picture is about dark mode); the English backend v1.0 (`mini-smart-home/backend`) with its TimescaleDB database (7 days of history from `npm run seed-history` and a refreshed summary book); **a mock MQTT broker instead of Mosquitto**, checking the same password file and access list; lab simulators for Node 1 and Node 2 and `tools/device-simulator.js` for the practice device `f00d00000001` (random example numbers). The accounts are the Module 20 ones, `admin@home.test` (Home Admin) and `viewer@home.test` (Home Guest); the account shown is `Home Guest (viewer)`, and no password, cookie, or IP address appears in any picture. The DevTools front-end was opened in a separate window of the same headless browser. The 375 px width is **DevTools device mode, not a real phone**; the Windows firewall dialog and a real phone were **not** tested by the author. All sources accessed October 2026.

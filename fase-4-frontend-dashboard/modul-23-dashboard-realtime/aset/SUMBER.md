# Sumber & atribusi gambar — Modul 23

Rekap semua gambar di folder ini. Diagram orisinal kurikulum berlisensi **CC BY 4.0**, dan file `.svg`-nya disertakan agar bisa diubah. Isi diagram berasal dari kode dashboard v0.2 modul ini (`src/soket.ts`, `src/toko.ts`, `src/waktu.ts`, `GrafikLive.tsx`, `Gauge.tsx`, `LencanaKoneksi.tsx`, `Lencana.tsx`) dan perilaku backend v1.0 Modul 21 yang diuji ulang penulis: acara Socket.IO `ikuti`, `telemetry`, dan `status`; alasan putus `io server disconnect`, `io client disconnect`, dan `transport close`; `GET /devices/:id/readings` dengan dan tanpa `bucket`; serta mode HP lewat alamat IP WiFi laptop. Angka sensor, jam, nama perangkat, dan IP laptop `192.168.1.10` di diagram adalah **contoh**: layar dashboard yang sebenarnya ada di tangkapan layar. Pada tangkapan layar, backend v1.0 dan databasenya sungguhan, tetapi pengirimnya program tiruan lab: simulator `f00d00000001` (`alat/` repo), Node 1/Node 2 tiruan, dan broker MQTT tiruan berkunci (bukan Mosquitto); angka sensornya contoh acak. Semua sumber diakses Oktober 2026.

# Sumber & atribusi gambar — Modul 24

Rekap semua gambar di folder ini. Diagram orisinal kurikulum berlisensi **CC BY 4.0**, dan file `.svg`-nya disertakan agar bisa diubah. Isi diagram berasal dari kode dashboard v1.0 dan backend 1.1 modul ini (`src/App.tsx`, `JagaMasuk.tsx`, `TataLetak.tsx`, `KhususAdmin.tsx`, `TombolSakelar.tsx`, `TombolPompa.tsx`, `WadahToast.tsx`, `src/aturan.ts`, `cek-skema.js`; backend `src/auth/keamanan.ts`, `src/schemas/aturan-dasar.ts`, `src/schemas/aturan.ts`, `src/services/otomasi.ts`) dan perilaku yang diuji ulang penulis lawan backend 1.1 dan databasenya yang sungguhan, dengan pengirim dan broker tiruan lab: broker MQTT tiruan berkunci (bukan Mosquitto), simulator `f00d00000001` (`alat/` modul ini), dan perangkat tiruan (patuh, lambat, bisu, dan nakal). Yang diuji: perintah `POST /devices/:id/command` dengan jawaban 200 (`ack.ok` benar dan salah), 409, 504 beserta pengiriman ulang oleh server, galat jaringan; satpam `onRequest` (403 untuk viewer); peta rute dan penjaga rute; galat formulir per kolom dan galat 400 dari backend; aturan siram `ambang-bawah` dengan simulator `tanah` dan `tandon`. Angka tanah dan sensor, jam, nama perangkat, dan IP laptop `192.168.1.10` di diagram adalah **contoh**; grafik aturan siram adalah ilustrasi tanpa skala waktu. Layar mini di diagram disederhanakan (tanpa menu dan warna aplikasi, tombol Nyala digambar gelap): tampilan dashboard yang sebenarnya ada di tangkapan layar. Bagian Node 1 sungguhan (Serial `ambang 20`) dibaca dari kode firmware v1.6.0, belum diuji penulis di papan sungguhan. Uji oleh orang lain dari HP sungguhan hanya digambarkan sebagai langkah kerja, bukan hasil uji. Pada tangkapan layar, dashboard v1.0 dan backend 1.1 beserta databasenya sungguhan, tetapi pengirimnya program tiruan lab: simulator `f00d00000001` (`alat/` modul ini), Node 1/Node 2 tiruan, dan broker MQTT tiruan berkunci (bukan Mosquitto); angka sensornya contoh, jam WIB; lebar 375 px = mode perangkat DevTools, bukan HP sungguhan. Tangkapan layar untuk Praktik 2–8 diambil dari kode akhir modul (sesudah Praktik 9): sebelum Praktik 9, warna teal dan teks abu-abu di layarmu sedikit lebih terang, dan menu **Aturan** di kepala dashboard baru ada mulai Praktik 7. Semua sumber diakses Oktober 2026.

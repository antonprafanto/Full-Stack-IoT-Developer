Rekap semua gambar di folder ini. Diagram orisinal kurikulum berlisensi **CC BY 4.0**, dan file `.svg`-nya disertakan agar bisa diubah. Angka sensor, nama perangkat, dan isi layar di diagram adalah **contoh**: layar dashboard yang sebenarnya ada di tangkapan layar. Semua sumber diakses Oktober 2026.

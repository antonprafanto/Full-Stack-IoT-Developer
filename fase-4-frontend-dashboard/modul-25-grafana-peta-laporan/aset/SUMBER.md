# Sumber & atribusi gambar — Modul 25

Rekap semua gambar di folder ini. Diagram orisinal kurikulum berlisensi **CC BY 4.0**, dan file `.svg`-nya disertakan agar bisa diubah. Isi diagram berasal dari kode modul ini (backend 1.2: `src/routes/perangkat.ts`, `src/routes/laporan.ts`, `src/services/laporan.ts`, `src/services/csv.ts`, `src/services/telegram.ts`, `src/config/env.ts`; frontend 1.1: `src/peta.ts`, `src/components/PetaPerangkat.tsx`, `src/halaman/Peta.tsx`; folder `grafana/`: `pengguna-grafana.sql`, `dashboards/kesehatan-sistem.json`, `alerting/node-diam.yaml`) dan perilaku yang diuji penulis di sebuah **Raspberry Pi 5 dengan Ubuntu 26.04 (arm64) yang berperan sebagai laptop**: Docker Engine 29 (bukan Docker Desktop), Grafana 13.2.4 (`grafana/grafana:13.2.4`), TimescaleDB 2.30.2, Mosquitto 2.0.22 berkunci, backend 1.2 dan frontend 1.1 modul ini, Chrome 156. Pengirim datanya program tiruan: simulator `f00d00000001` dan **Kebun tiruan** `f00d000000b2` (`alat/` modul ini), bukan Node 1/Node 2 sungguhan; Telegram = **server Bot API tiruan** di lab penulis, bukan bot Telegram asli, jadi teks pesan di diagram adalah teks yang diterima server tiruan itu. Angka waktu *alert* di diagram adalah rekaman **dua larian** di lab penulis yang ditulis sebagai rentang (🔴 simulator 5 min 46 s – 5 min 58 s, Kebun 5 min 55 s – 11 min 10 s sesudah dicabut, 📴 ±17 menit, ✅ Grafana +3 min 22 s – 4 min 26 s); kotak pesan Telegram dan gladi laporan (00.04.00 WIB, 326 byte) masing-masing dari satu larian, jadi angka di larianmu bisa bergeser sampai sekitar satu menit, tetap di dalam rumusnya; jam ditulis dalam WIB. Hal yang khusus Windows/macOS (Docker Desktop, `host.docker.internal`) tidak diuji penulis. Titik peta (sekitar Monas, Jakarta) **fiktif**, IP laptop `192.168.1.10` dan angka sensor di diagram adalah **contoh**; layar Peta dan layar mini di diagram adalah **ilustrasi** (ubin, jalan, dan warna aplikasi disederhanakan): tampilan sebenarnya ada di tangkapan layar. Pesan `⏰ … terlewat` di diagram laporan memakai format dari kode `laporan.ts` dengan jam contoh 07.00 WIB. Tangkapan layar diambil penulis di mesin yang sama dengan **Chrome 156 tanpa layar** (lebar 1280 px; lebar 375 px = mode perangkat Chrome, bukan HP sungguhan), zona waktu `Asia/Jakarta`, lawan Grafana OSS 13.2.4 (tema bawaan gelap), database TimescaleDB 2.30.2, backend 1.2 dan frontend 1.1 modul ini yang sungguhan; datanya dari pengirim tiruan yang sama (simulator `f00d00000001` dan **Kebun tiruan** `f00d000000b2`) ditambah riwayat latihan dari `npm run isi-riwayat`. Telegram tiruan memakai token palsu dan `chat_id` palsu, jadi tidak ada tangkapan layar aplikasi Telegram. Laporan CSV **tidak dibuka di Excel atau LibreOffice** (tidak ada spreadsheet di mesin penulis): isinya ditampilkan sebagai teks terminal (`cat`, `xxd`). Angka sensor dan jam di tangkapan layar adalah contoh; jam di layar Grafana dan Peta ditulis WIB, sedangkan di `laporan-csv` jam log backend = jam mesin lab (WITA) dan jam server tiruan = UTC, keduanya diberi keterangan di gambar. Semua sumber diakses Oktober 2026.

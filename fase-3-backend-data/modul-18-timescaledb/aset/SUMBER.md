# Sumber & atribusi gambar — Modul 18

Rekap semua gambar di folder ini. Diagram orisinal kurikulum berlisensi **CC BY 4.0**, dan file `.svg`-nya disertakan agar bisa diubah. Tangkapan layar `/docs` diambil dari backend v0.3 modul ini (Swagger UI 5.32.6 lewat @fastify/swagger-ui 6.1.2) yang dijalankan di laptop penulis, dengan data latihan dari `npm run isi-riwayat`. Angka di diagram (jumlah jilid, ukuran, sidik jari) berasal dari lab penulis untuk modul ini. Semua sumber diakses Oktober 2026.

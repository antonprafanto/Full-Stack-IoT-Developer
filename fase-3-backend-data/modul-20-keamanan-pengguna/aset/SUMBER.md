# Sumber & atribusi gambar — Modul 20

Rekap semua gambar di folder ini. Diagram orisinal kurikulum berlisensi **CC BY 4.0**, dan file `.svg`-nya disertakan agar bisa diubah. Angka, pesan, dan contoh di diagram berasal dari lab penulis untuk modul ini: backend v0.5 di laptop Windows dengan database lab, Bruno, curl, dan PowerShell. Contoh sidik jari bcrypt, gelang JWT, dan kartu terusan di gambar dibuat khusus untuk contoh: tidak satu pun milik akun atau backend sungguhan. Semua sumber diakses Oktober 2026.

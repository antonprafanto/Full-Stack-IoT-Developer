# Sumber & atribusi gambar — Modul 21

Rekap semua gambar di folder ini. Diagram orisinal kurikulum berlisensi **CC BY 4.0**, dan file `.svg`-nya disertakan agar bisa diubah. Angka, pesan, dan contoh di diagram berasal dari lab penulis untuk modul ini: backend v1.0 dan broker tiruan di laptop Windows dengan database lab, serta firmware Node 1 v1.6.0 yang diuji di Wokwi. **Mosquitto tidak terpasang di laptop penulis minggu ini**, jadi perilaku dan teks log broker di diagram ditulis dari kode sumber resmi Mosquitto 2.0.21 (Pi) dan 2.1.2 (laptop); reaksi pustaka klien diuji lewat broker tiruan. Contoh kunci dan sidik jari di gambar dibuat khusus untuk contoh: tidak satu pun milik perangkat atau akun sungguhan. Semua sumber diakses Oktober 2026.

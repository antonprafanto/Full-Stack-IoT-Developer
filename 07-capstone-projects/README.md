# 🏆 07 - Industrial Capstone Projects & Portofolio

Folder ini berisi dokumentasi rancangan sistem, skematik sirkuit, kode firmware, backend server, dan frontend dashboard untuk proyek akhir skala industri (**Fase 12**):

## 📂 Pilihan Proyek Capstone Enterprise:
- `project-a-iiot-power-quality/` : Smart Factory Power Quality & Predictive Machine Maintenance (ESP32-S3 + Modbus RS-485 + TinyML FFT + Kafka + Next.js).
- `project-b-solar-smart-agri/` : Solar-Powered Nano-Gated LoRaWAN Smart Agriculture Grid (ESP32-C6 + TPL5110 + Li-SOCl2 + ChirpStack + InfluxDB + Mapbox).
- `project-c-coldchain-tracker/` : Cold-Chain Logistics & Pharmaceutical Asset Tracker (ESP32 + SIM7000G Seluler + GPS + Protobuf + FastAPI + WebSocket Map).

---

## 🎯 Target Portofolio:
1. Membangun sistem IoT terintegrasi ujung-ke-ujung (*End-to-End*) yang memenuhi standar industri.
2. Menguji ketahanan sistem terhadap skenario terburuk (*Network blackout*, *Power dip*, *Vibration noise*).
3. Mendokumentasikan proyek secara profesional untuk dipamerkan di GitHub dan LinkedIn.

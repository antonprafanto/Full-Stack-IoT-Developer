## 🎯 Tanda lulus Fase 0

Sebelum lanjut ke Fase 1, pastikan tiga bukti ini sudah ada di repositori GitHub-mu ([Silabus §8](../SILABUS.md#8-evaluasi--tanda-kelulusan-tiap-fase)):

1. Kuis setiap modul (5 soal) **≥ 4 benar**.
2. **Proyek checkpoint:** lampu lalu lintas 3 LED dalam C++ (Modul 3) serta skrip statistik dan server mini dalam JavaScript (Modul 4).
3. **Artefak:** kode dan tangkapan layar Wokwi tersimpan di GitHub.

## 📂 Isi setiap folder modul

| Isi | Gunanya |
| :--- | :--- |
| `README.md` | Artikel modulnya — mulai membaca dari sini. GitHub menampilkannya otomatis saat kamu membuka folder modul. |
| `kode/` | Semua kode yang dipakai di artikel, satu folder per program, siap disalin ke Wokwi atau Arduino IDE. |
| `aset/` | Gambar-gambar artikel, beserta `SUMBER.md` yang mencatat sumber dan lisensi setiap gambar. |

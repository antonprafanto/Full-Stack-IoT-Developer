# Sumber & atribusi gambar — Modul 29

Rekap semua gambar di folder ini. Diagram orisinal kurikulum berlisensi **CC BY 4.0**, dan file `.svg`-nya disertakan agar bisa diubah. Isi diagram berasal dari kode modul ini (`.github/workflows/ci.yml` dengan enam job `periksa`, `uji`, `bangun`, `staging`, `tandai-rilis`, `pasang-vps`; `skrip/pasang.sh`, `skrip/uji-asap.sh`, `skrip/cek-versi.mjs`; `skrip/systemd/rumahpintar-perbarui.service` dan `.timer`; backend 2.0.0: `src/app.ts`, `src/integrasi/` dengan 20 *integration test*, `src/config/versi-server.ts`, `src/routes/kesehatan.ts`, `Dockerfile`; dashboard 2.0.0: tiga berkas tes Vitest dan `Dockerfile`; `compose.cloud.yml`, `CHANGELOG.md`, `.github/pull_request_template.md`, README akar dan `edge/README.md`), dari dokumen resmi yang dibaca penulis (GitHub Docs: Actions, Container registry, aturan cabang; Docker Docs: build multi-platform; systemd.timer; OpenSSH `sshd` dan `ssh_config`; SemVer 2.0.0; Keep a Changelog), dan dari perilaku yang diuji penulis di sebuah **Raspberry Pi 5 dengan Ubuntu 26.04 (arm64)**: Docker Engine 29.1.3 dengan Docker Compose 2.40.3 dan buildx 0.30.1, Node.js 24.21.0 di "laptop" dan `node:24.22.1-alpine3.24` di kontainer job, TimescaleDB 2.30.2, Mosquitto 2.1.2, Chrome 156. **Penulis tidak punya akun GitHub, paket GHCR, VPS, mesin sewaan GitHub (*runner*), atau Pi kedua.** Karena itu seluruh `ci.yml` dijalankan apa adanya oleh robot **tiruan** di Pi 5 itu (*forge* Gitea + Gitea Runner + kontainer Docker-in-Docker atas izin pengguna; rinciannya di kalimat tangkapan layar di bawah), GHCR ditiru toko image lokal `registry:3.1.2`, SSH robot diuji dengan OpenSSH sungguhan ke "VPS" tiruan, jam weker Pi ditiru penjadwal sederhana, dan unit systemd hanya diperiksa dengan `systemd-analyze verify` (systemd 259), tidak dijalankan oleh systemd sungguhan. Angka lab di diagram ditulis dengan tanda "lab tiruan" atau "lab penulis"; waktu robot GitHub sungguhan, lama tarikan image job `staging` di GitHub (±1,1 GB), jadwal timer sesudah *reboot*, dan image amd64 yang dijalankan **belum diukur** dan tidak ditulis sebagai hasil. Layar GitHub di `kotak-merge-aturan-cabang` adalah **rekonstruksi** dari dokumen GitHub, bukan tangkapan layar. Alamat `203.0.113.10` (VPS), `iot.namaanda.my.id`, pengguna `rumah` (VPS) dan `budi` (Pi), serta nama cabang contoh `coba/merah` dan `perbaikan/teks-masuk` adalah contoh, sama gayanya dengan Modul 27–28. Tangkapan layar diambil penulis di **Raspberry Pi 5 dengan Ubuntu 26.04 (arm64)** dengan **Chrome 156 tanpa layar** (lebar 1280 px sebagai laptop; lebar 375 px = **mode perangkat Chrome di mesin yang sama, bukan HP sungguhan**), zona waktu `Asia/Jakarta`, 4 November 2026, pada kode modul ini apa adanya (kode BEKU 1 Modul 29): backend + dashboard **2.0.0**, lalu **2.0.1** (PR kecil Praktik 12), Caddy 2.11.7, Mosquitto 2.1.2, TimescaleDB 2.30.2, dari `compose.cloud.yml` dan `edge/compose.edge.yml`. **Penulis tidak memakai akun GitHub atau GHCR, VPS, atau Raspberry Pi tambahan untuk modul ini, jadi seluruh jalur robot → VPS/Pi ditiru di mesin itu** (atas izin pengguna: kontainer `--privileged` Docker-in-Docker khusus lab akhir Modul 29, dihapus sesudahnya): "GitHub" = **forge Gitea 28.2.0** (repo publik lab `PembacaM29/rumah-pintar-mini` berisi riwayat proyek Modul 28); "GitHub Actions" = **Gitea Runner 5.2.4** yang menjalankan `.github/workflows/ci.yml` modul ini apa adanya (action resmi diunduh runner dari github.com tanpa akun) di Docker robot tiruan; "GHCR" = toko image `registry:3.1.2` **tanpa auth** yang di lorong lab bernama `ghcr.io`; "VPS" dan "Pi" = kontainer `docker:29.9.2-dind` + sshd (Alpine, **bukan** Ubuntu VPS dan **bukan** Raspberry Pi OS); "internet" = lorong (*network*) Docker. Dashboard "VPS" dibuka di `http://172.29.50.31` (**HTTP lokal, tanpa domain dan HTTPS**; teks naskah menulis `https://iot.namaanda.my.id`; alamat lab tampak di halaman `/api/docs`, subjudul komposit menulis keduanya); dashboard "Pi gratis" lewat **terowongan SSH lab** (pengganti Cloudflare Tunnel). *Service worker* PWA diizinkan di HTTP lokal hanya di profil Chrome lab (bendera `--unsafely-treat-insecure-origin-as-secure`; dashboard pembaca = HTTPS). **Chrome tanpa layar hanya menangkap isi halaman: bilah alamat, terminal, HP, dan layar GitHub tidak pernah tampak** (dan tidak ditiru); dua komposit opsional menampilkan halaman **Gitea** dan berjudul "TIRUAN lokal (Gitea), BUKAN layar GitHub". Perangkat di layar adalah **simulator** `alat/simulator-perangkat.js` modul sebelumnya (Node 1 tiruan `f00d00000001` "Latihan ruang tamu", firmware tiruan 1.7.0; angka sinyal/RAM = angka simulator); riwayat 7 hari = `isi-riwayat.ts`; rilis 1.7.1 = **berkas tiruan** `alat/buat-bin-tiruan.js`. Akun yang dipakai = akun contoh lab `admin@rumah.test` (tampak hanya sebagai `Admin Rumah (admin)`; kolom Email layar Masuk berisi contoh bawaan `viewer@rumah.test`, kolom Sandi kosong) dan pemilik repo lab `PembacaM29`; tidak ada token, kunci, sandi, atau cookie di gambar. Angka dan jam adalah contoh dari lab tiruan (4 Nov 2026, WIB), **bukan angka GitHub** (runner x64, VPS amd64). Semua sumber diakses Oktober–November 2026.

# Sumber & atribusi gambar — Modul 26

Rekap semua gambar di folder ini. Diagram orisinal kurikulum berlisensi **CC BY 4.0**, dan file `.svg`-nya disertakan agar bisa diubah. Isi diagram berasal dari kode modul ini (`compose.cloud.yml`, `.env.example`, `edge/compose.edge.yml`, `edge/pusat.conf`, `edge/gerbang.conf`, `edge/jembatan.contoh.conf`; backend 1.3: `Dockerfile`, `.dockerignore`, `package.json`; frontend 1.2: `Dockerfile`, `caddy/Caddyfile`, `src/soket.ts`; folder `grafana/`: `provisioning/`, `dashboards/kesehatan-sistem.json`, `pengguna-grafana.sql`) dan perilaku yang diuji penulis di sebuah **Raspberry Pi 5 dengan Ubuntu 26.04 (arm64) yang memerankan laptop dan sekaligus Pi**: Docker Engine 29.1.3 dengan Docker Compose 2.40.3 (paket Ubuntu, bukan Docker Desktop; perintah `docker compose` di Docker Desktop sama), TimescaleDB 2.30.2, Grafana 13.2.4, Mosquitto 2.1.2, Caddy 2.11.7, Node.js 24.22.1, Chrome 156. Gerbang Pi dijalankan sebagai proyek Compose kedua di mesin yang sama dengan loket lain, bukan di Raspberry Pi OS sungguhan, dan perangkatnya simulator `f00d00000001`, bukan ESP32 sungguhan; Telegram = **server Bot API tiruan** di lab penulis, dan GitHub Container Registry (GHCR) ditiru dengan **registry lokal** `registry:3.1.2` di `127.0.0.1`, jadi login GHCR, halaman paket, dan tarik image dari GHCR publik **tidak direkam**. Angka di diagram adalah angka lab penulis di Pi 5 (arm64) pada kode akhir modul (uji akhir 28 Okt 2026): ukuran image (`docker image ls`: di disk / unduhan terkompres), waktu build, waktu `docker compose push`, uji laptop bersih, dan garis waktu `docker compose up -d` (detik di layar Compose; laptopmu bisa lebih cepat atau lebih lambat, dan waktu build berubah menurut jaringan dan *cache* npm). Pembanding `npm ci` penuh (alat pengembang ikut) (404 MB / 94,8 MB) berasal dari uji riset penulis dengan basis `node:24.21.0-alpine`. Perilaku *restart policy* saat *reboot* atau Docker dinyalakan ulang ditulis menurut dokumen dan kode Docker, **tidak diuji** penulis; `docker compose up -d --build` di laptop amd64 juga tidak diuji. Hal yang khusus Windows/macOS (Docker Desktop, WSL 2, PowerShell) tidak diuji penulis. IP laptop `192.168.1.10` dan IP Pi `192.168.1.37` adalah **contoh**, sama dengan modul sebelumnya. Tangkapan layar diambil penulis di **Raspberry Pi 5 dengan Ubuntu 26.04 (arm64) yang berperan sebagai laptop**, dengan **Chrome 156 tanpa layar** (lebar 1280 px; lebar 375 px = mode perangkat Chrome di mesin yang sama, **bukan HP sungguhan**), zona waktu `Asia/Jakarta`, lawan seluruh rumah yang dijalankan **Docker Compose 2.40.3** (Docker Engine 29.1.3, paket Ubuntu, bukan Docker Desktop) dari `compose.cloud.yml` modul ini apa adanya, ditambah satu berkas Compose khusus lab untuk Telegram tiruan (tidak ada di proyek pembaca): TimescaleDB 2.30.2, Mosquitto 2.1.2, backend 1.3.0 dan web 1.2.0 (Caddy 2.11.7) modul ini yang sungguhan, Grafana OSS 13.2.4 (tema bawaan gelap) dengan *provisioning* dari folder `grafana/` modul ini, dan Uptime Kuma 2.5.8. Lemari Grafana "Modul 25" dibuat penulis lewat API yang sama dengan layar Modul 25, lalu diambil alih lewat layar seperti Praktik 7.3. Pengirim datanya program tiruan: simulator `f00d00000001` dan **Kebun tiruan** `f00d000000b2` (`alat/` modul ini) ditambah riwayat latihan dari `isi-riwayat`, bukan Node 1/Node 2 sungguhan; Telegram = **server Bot API tiruan** di lab penulis (token palsu, `chat_id` palsu), jadi tidak ada tangkapan layar aplikasi Telegram. Tidak ada tangkapan layar Docker Desktop atau GitHub Container Registry (keduanya tidak diuji penulis). Alamat IP LAN mesin lab disamarkan menjadi `192.168.1.10`. Angka sensor dan jam adalah contoh; jam ditulis WIB. Semua sumber diakses Oktober 2026.

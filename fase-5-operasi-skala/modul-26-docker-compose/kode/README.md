# 🏠 Proyek Rumah Pintar Mini — versi rujukan

🌐 **Bahasa Indonesia** · [English](../../../en/mini-smart-home/README.md)

Folder ini berisi **kode proyek benang merah** kurikulum dalam versi terbarunya. Setiap modul menambahkan satu-dua bagian; folder `kode/` di setiap modul menyimpan "potret" pada minggu itu, sedangkan folder ini selalu berisi versi paling baru.

> **Untuk pembelajar:** proyekmu sendiri tinggal di repositori milikmu, `rumah-pintar-mini`, yang dibuat dengan GitHub Desktop di [Modul 3](../../../fase-0-fondasi/modul-03-cpp-untuk-esp32/README.md#-tambahan-ke-rumah-pintar-mini). Folder ini adalah **kunci jawaban dan rujukan**. Kerangka v0.1.0 (Modul 3), folder `alat/` (Modul 4), dan `PETA-PIN.md` (Modul 5) memang disalin utuh. Mulai Modul 5, isi firmware (dan mulai Modul 16, backend) kamu tulis sendiri dengan panduan di setiap modul — bandingkan dengan milikmu kalau ada yang macet, tetapi jangan menyalinnya mentah-mentah.

## Menjalankan seluruh sistem dalam satu perintah (Modul 26)

Sejak Modul 26, semua layanan pusat menyala bersama dari akar proyek di laptop yang hanya punya Git dan Docker (Docker Desktop di Windows dan macOS, Docker Engine di Linux): tanpa Node.js dan tanpa `npm install`. Langkah lengkapnya, termasuk memindahkan database dan Grafana Modul 17–25 tanpa kehilangan data, ada di [Modul 26](../README.md).

1. *Clone* repositorimu, lalu buka terminal di foldernya (akar proyek, tempat `compose.cloud.yml`).
2. Salin `.env.example` menjadi `.env`, isi lima rahasianya dengan teks acak (perintah pembuatnya tertulis di kepala `.env.example`) dan `TOKO_IMAGE`. Di Linux, macOS, dan Pi: `chmod 600 .env`.
3. Laptop baru saja (lemari Modul 17 dan 25 belum ada): `docker volume create rumahpintar-data` dan `docker volume create rumahpintar-grafana-data`. Laptop yang masih menjalankan kontainer lama `rumahpintar-db` dan `rumahpintar-grafana` mengikuti urutan pindahan di Modul 26 Praktik 4 lebih dulu: kontainer lama dihentikan dan dihapus sebelum Compose menyala, lemarinya tetap.
4. `docker compose up -d --wait`. Pertama kali, Compose menarik *image* dari toko *image*, atau membangun *image* backend dan dashboard sendiri kalau belum ada di toko (beberapa menit). Laptop ini berbeda jenis prosesor dengan laptop yang membangun *image* di toko (Intel atau AMD = `amd64`, Mac Apple silicon atau Pi = `arm64`)? Tambahkan `--build` (`docker compose up -d --wait --build`): *image* di toko hanya cocok untuk prosesor pembuatnya, jadi Compose membangunnya sendiri (lebih lama, butuh unduhan npm). Perintah ini baru selesai sesudah semua layanan siap: layanan panjang tertulis `Healthy`, layanan sekali jalan `Exited`. Periksa dengan `docker compose ps -a` (sekali jalan: `Exited (0)`).
5. Laptop baru: buat akun admin pertama dengan `docker compose exec backend node src/db/kelola-pengguna.ts tambah admin@rumah.test "Admin Rumah" admin` (sandi ditanyakan dua kali). Dashboard ada di **`http://localhost`**, Grafana di **`http://localhost:3000`**.

| Perintah (dari akar proyek) | Gunanya |
| :--- | :--- |
| `docker compose ps -a` | keadaan semua layanan, termasuk layanan sekali jalan yang sudah selesai (`Exited (0)`); tanpa `-a` layanan itu tidak tampil |
| `docker compose logs -f backend` | log satu layanan (juga `mosquitto`, `grafana`, `web`, …); **Ctrl + C** hanya berhenti membaca |
| `docker compose down` lalu `docker compose up -d` | mematikan dan menyalakan lagi seluruh rumah; riwayat tetap (buktikan dengan [`skrip/sidik-jari.sql`](skrip/sidik-jari.sql)) |
| `docker compose stop mosquitto`, lalu `docker compose start mosquitto` | broker pusat mendengar di semua antarmuka laptop dan ikut menyala setiap Docker menyala: hentikan sebelum laptop masuk WiFi umum (kafe, kampus), nyalakan lagi di rumah |

**Jangan** `docker compose down -v` (menghapus lemari berkas sandi broker), dan jangan `docker volume rm` atau `prune` untuk lemari `rumahpintar-data` dan `rumahpintar-grafana-data`: tanpa cadangan, riwayatmu hilang. `.env` dan keluaran `docker compose config` berisi semua rahasia: jangan ditempel ke forum, isu, atau AI. Rincian setiap layanan ada di `backend/README.md`, `frontend/README.md`, `grafana/README.md`, dan `edge/README.md`.

## Yang akan menyusul

Sesuai [struktur di Silabus](../../../SILABUS.md#9-struktur-folder-repositori): `backend/` tumbuh sampai Modul 21 (database, aturan otomatis, dan keamanan), lalu mendapat v1.1 di Modul 24 (aturan siram dan hapus aturan) dan v1.2 di Modul 25 (lokasi perangkat dan laporan harian). `frontend/` lahir di [Modul 22](../../../fase-4-frontend-dashboard/modul-22-react-dasar/README.md) dan tumbuh sampai Modul 25 (data *live* dan grafik, kendali dan peran, lalu peta perangkat); Grafana untuk tim teknis tidak tinggal di `frontend/`, melainkan di `grafana/` sejak Modul 25. Sejak Modul 26, seluruh sistem berjalan dalam Docker Compose: `compose.cloud.yml` di laptop dan `edge/compose.edge.yml` di Raspberry Pi, masih di jaringan rumah. Berikutnya, Modul 27 memindahkan berkas Compose yang sama ke server di internet (VPS) dengan domain dan HTTPS.

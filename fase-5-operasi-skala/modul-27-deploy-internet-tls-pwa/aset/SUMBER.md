# Sumber & atribusi gambar — Modul 27

Rekap semua gambar di folder ini. Diagram orisinal kurikulum berlisensi **CC BY 4.0**, dan file `.svg`-nya disertakan agar bisa diubah. Isi diagram berasal dari kode modul ini (`compose.cloud.yml`, `.env.example`, `frontend/caddy/Caddyfile`, `edge/pusat-internet.conf`, `edge/gerbang.conf`, `edge/jembatan.contoh.conf`, `edge/acl-broker`, `edge/compose.edge.yml`, `edge/.env.example`, `skrip/salin-sertifikat.sh`, `skrip/perbarui-sertifikat-mqtt.sh`, `skrip/cek-susulan.sql`; backend 1.4: `src/config/env.ts`, `src/services/perintah.ts`; frontend 1.3: `vite.config.ts`, `public/`, `README.md`) dan perilaku yang diuji penulis di sebuah **Raspberry Pi 5 dengan Ubuntu 26.04 (arm64) yang memerankan laptop, VPS, dan Pi sekaligus**: Docker Engine 29.1.3 dengan Docker Compose 2.40.3, Caddy 2.11.7, Mosquitto 2.1.2, TimescaleDB 2.30.2, Grafana 13.2.4, Node.js 24.22.1, Chrome 156. **Penulis tidak punya VPS, domain, akun Cloudflare, HP, jaringan seluler, ESP32 dengan TLS, atau router yang bisa dicabut.** Semuanya ditiru di mesin itu: "internet" = lorong (*network*) Docker, Let's Encrypt = **Pebble 2.10.1** (CA ACME tiruan buatan Let's Encrypt untuk uji), DNS = **pebble-challtestsrv 2.10.1**, nama domain lab = `iot.contoh.test` dan `mqtt.contoh.test` (diagram menulis nama pembaca `iot.namaanda.my.id` dan `mqtt.namaanda.my.id`; subjudul komposit menulis keduanya), "cabut internet rumah" = memutus kontainer broker gerbang dari lorong itu (`docker network disconnect`), dan HP = Chrome tanpa layar selebar 412 px (uji) atau mode perangkat 375 px (tangkapan). Angka dari lab adalah angka **lab tiruan** pada kode modul ini: garis waktu cabut 10 menit, kenaikan antrean jembatan, dan hasil `cek-susulan.sql` dari uji ulang pada kode akhir (30 Okt 2026); waktu terbit sertifikat dan tiga tamu `trustProxy` dari lab kode 29 Okt 2026, sebelum dua perbaikan kecil (sesi tetap backend di broker dan nama klien di pintu 8883) yang tidak menyentuh angka itu. Semuanya bukan angka Let's Encrypt, VPS, atau jaringan rumah sungguhan; router dan jaringan seluler sungguhan bisa membuat "jendela buta" lebih pendek atau lebih panjang. Pembanding "bunyi Silabus asli" di diagram jembatan berasal dari uji ulang penulis pada kode akhir dengan setelan Silabus dipasang sementara (baris listrik padam: uji riset penulis dengan lab tiruan yang sama). Rantai sertifikat Let's Encrypt digambar dari dokumen Let's Encrypt dan dicek penulis dengan `openssl s_client` ke situs ber-Let's Encrypt (`api.open-meteo.com`, 29 Okt 2026); Pebble tidak meniru rantai itu, jadi jembatan dan ESP32 terhadap rantai Let's Encrypt sungguhan **belum diuji**. Langkah ufw, SSH, registrar, Cloudflare, dan pemasangan aplikasi di HP ditulis menurut dokumen resminya dan **tidak diuji** penulis. IP VPS `203.0.113.10` adalah alamat **contoh** (blok dokumentasi), sedangkan IP laptop `192.168.1.10` dan IP Pi `192.168.1.37` adalah contoh yang sama dengan modul sebelumnya. Tangkapan layar diambil penulis di **Raspberry Pi 5 dengan Ubuntu 26.04 (arm64)** dengan **Chrome 156 tanpa layar** (lebar 1280 px sebagai laptop; lebar 375 px = **mode perangkat Chrome di mesin yang sama, bukan HP sungguhan dan bukan jaringan seluler**), zona waktu `Asia/Jakarta`, pada kode modul ini apa adanya: backend 1.4.0, dashboard 1.3.0 (PWA), Caddy 2.11.7, Mosquitto 2.1.2, TimescaleDB 2.30.2, Grafana OSS 13.2.4 (tema bawaan gelap) dari `compose.cloud.yml` dan `edge/compose.edge.yml`, Docker Engine 29.1.3 dengan Docker Compose 2.40.3. **Penulis tidak punya VPS, domain, Cloudflare, HP, atau router yang bisa dicabut, jadi semuanya ditiru di mesin itu:** "internet" = lorong (*network*) Docker; "VPS" = kontainer pemegang satu alamat di lorong itu; Let's Encrypt = **Pebble 2.10.1** (CA ACME tiruan buatan Let's Encrypt untuk uji); DNS = **pebble-challtestsrv 2.10.1**; nama domain lab `iot.contoh.test` (teks naskah menulis `iot.namaanda.my.id`; surel akun teman sementara `teman@contoh.test` tampak di layar Masuk); Chrome menerima sertifikat Pebble hanya di profil lab, tanpa menyentuh sertifikat sistem; "cabut internet rumah" = memutus kontainer broker gerbang Pi tiruan dari lorong itu. **Chrome tanpa layar hanya menangkap isi halaman: bilah alamat, gembok, dialog pemasangan aplikasi, dan DevTools tidak pernah tampak** (dan tidak ditiru). Pengirim datanya program tiruan: simulator `f00d00000001` dan **Kebun tiruan** `f00d000000b2` (`alat/`) ditambah riwayat latihan dari `isi-riwayat`, bukan Node 1/Node 2 sungguhan; Telegram = server Bot API tiruan (tidak ada tangkapan aplikasi Telegram). Akun di tangkapan = akun uji lab (sandi tidak terlihat). Angka dan jam adalah contoh dari lab tiruan (30 Okt 2026, WIB), bukan angka VPS, Let's Encrypt, atau jaringan rumah sungguhan.

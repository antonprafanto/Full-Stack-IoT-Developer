# Sumber & atribusi gambar — Modul 28

Rekap semua gambar di folder ini. Diagram orisinal kurikulum berlisensi **CC BY 4.0**, dan file `.svg`-nya disertakan agar bisa diubah. Isi diagram berasal dari kode modul ini (`KONTRAK-DATA.md` 1.6; firmware Node 1 1.7.0: `konfigurasi.h`, `masa-uji.cpp`, `pembaruan.cpp`, `periksa-ota.cpp`, `jaringan.cpp`, `klaim.cpp`; backend 1.5: `src/routes/firmware.ts`, `src/routes/klaim.ts`, `src/routes/perangkat.ts`, `src/services/ota.ts`, `src/services/akun-broker.ts`, `migrasi/011_ota_dan_armada.sql`; dashboard 1.4: `src/armada.ts`, `src/components/DaftarRilis.tsx`, `TindakanArmada.tsx`, `UnggahFirmware.tsx`, `BuatKodeKlaim.tsx`; `frontend/caddy/Caddyfile`, `compose.cloud.yml`, `.env.example`, `edge/gerbang.conf`, `edge/jembatan.contoh.conf`, `edge/acl-broker`, `PETA-PIN.md` versi 7), dari sumber resmi paket Arduino-ESP32 **3.3.12** dan ESP-IDF **v5.5.5** yang dibaca penulis, dan dari perilaku yang diuji penulis di sebuah **Raspberry Pi 5 dengan Ubuntu 26.04 (arm64)** yang memerankan laptop, VPS, dan Pi sekaligus: Docker Engine 29.1.3 dengan Docker Compose 2.40.3, Caddy 2.11.7, Mosquitto 2.1.2 (*dynamic security*), Node.js 24.21.0 (simulator dan uji di laptop; image backend `node:24.22.1-alpine3.24`), Chrome 156. **Penulis tidak punya ESP32 di meja, papan ekspansi, kotak proyek, solder, atau multimeter.** Firmware 1.7.0 di diagram **sudah dikompilasi** penulis (`arduino-cli` 1.5.1 + paket esp32 3.3.12, setelan pembaca sejak Modul 10: papan ESP32 Dev Module, Flash Mode DIO, Minimal SPIFFS; tanpa satu pun perubahan kode karena kompilator) **tetapi belum dijalankan di papan sungguhan**: logika pemeriksa perintah dan mesin status pembaruan/rollback diuji di laptop dengan `g++` dan tiruan pustaka ESP32, sedangkan semua perangkat di lab adalah **simulator** `alat/simulator-perangkat.js` (rancangan firmware 1.7.0) dan berkas `.bin` di lab adalah berkas **tiruan** (bait pertama `0xE9`, bukan firmware), kecuali rilis 1.7.1 di lab akhir dan komposit: **firmware asli** hasil kompilasi penulis yang hanya diunggah, diunduh, dan diperiksa SHA-256-nya, tidak dijalankan. "Internet" = lorong (*network*) Docker, HTTPS = Let's Encrypt tiruan **Pebble 2.10.1**, Telegram = server tiruan. Angka lab ditulis dengan tanda "lab tiruan" atau "simulator"; waktu pembaruan di papan, rollback di papan, dan "satu menit" klaim dengan HP sungguhan **belum diukur** dan tidak ditulis sebagai hasil. Ukuran firmware 1.7.0 di `dua-rak-otadata` = angka `Sketch uses` hasil kompilasi penulis dengan setelan pembaca itu; akibat menghapus `extern "C"` di `mesin-status-rollback` = hasil kompilasi penulis juga (bukan percobaan di papan). Alamat `192.168.1.37` (Pi), `192.168.1.10` (laptop), dan `iot.namaanda.my.id` adalah contoh, sama dengan Modul 10–27; nama perangkat di tabel armada adalah contoh. Tangkapan layar diambil penulis di **Raspberry Pi 5 dengan Ubuntu 26.04 (arm64)** dengan **Chrome 156 tanpa layar** (lebar 1280 px sebagai laptop; lebar 375 px = **mode perangkat Chrome di mesin yang sama, bukan HP sungguhan**), zona waktu `Asia/Jakarta`, 2 November 2026, pada kode modul ini apa adanya (cabang `fitur/armada` = kode modul; hanya `konfigurasi.h` sudah 1.7.1 seperti Praktik 6): backend 1.5.0, dashboard 1.4.0, Caddy 2.11.7, Mosquitto 2.1.2 dengan *dynamic security* di broker pusat dan gerbang Pi, TimescaleDB 2.30.2, dari `compose.cloud.yml` dan `edge/compose.edge.yml`, Docker Engine 29.1.3 dengan Docker Compose 2.40.3. **Penulis tidak punya ESP32 di meja, papan ketiga, HP, VPS, atau domain, jadi semuanya ditiru di mesin itu:** "internet" = lorong (*network*) Docker; "VPS" = kontainer pemegang satu alamat di lorong itu; Let's Encrypt = **Pebble 2.10.1** (CA ACME tiruan buatan Let's Encrypt untuk uji); DNS = **pebble-challtestsrv 2.10.1**; nama domain lab `iot.contoh.test` (teks naskah menulis `iot.namaanda.my.id`; nama lab tidak tampak di tangkapan, subjudul komposit menulis keduanya); Chrome menerima sertifikat Pebble hanya di profil lab, tanpa menyentuh sertifikat sistem. **Chrome tanpa layar hanya menangkap isi halaman: bilah alamat, gembok, DevTools, Serial Monitor, Arduino IDE, papan, dan HP tidak pernah tampak** (dan tidak ditiru). Semua "perangkat" di layar **Armada** adalah **simulator** `alat/simulator-perangkat.js` modul ini (rancangan firmware 1.7.0): Node 1 tiruan `f00d00000001` "Latihan ruang tamu" (dijalankan dulu sebagai firmware 1.6.0, lalu 1.7.0 seperti sesudah Praktik 5), perangkat latihan `f00d00000005` "Latihan dapur", **Kebun tiruan** `f00d000000b2`, dan papan ketiga tiruan `f00d00000003`; angka kesehatan (sinyal WiFi, RAM, lama menyala) adalah angka acak simulator, bukan papan sungguhan. Berkas 1.7.1 yang diunggah dan diunduh adalah **firmware asli hasil kompilasi penulis** (setelan pembaca, `arduino-cli` 1.5.1 + paket esp32 3.3.12), tetapi simulator hanya memeriksa ukuran, bait pertama, dan SHA-256-nya, **tidak menjalankannya**; rilis uji 1.7.2 adalah **berkas tiruan** `alat/buat-bin-tiruan.js --uji`. Akun di tangkapan = akun contoh lab `admin@rumah.test` / `viewer@rumah.test` (sandi tidak terlihat); kode klaim disamarkan `XXXX-XXXX` **sebelum** tangkapan diambil. Angka dan jam adalah contoh dari lab tiruan (2 Nov 2026, WIB), bukan angka ESP32 lewat WiFi, VPS, atau Let's Encrypt sungguhan. Gambar portal WiFi adalah **ilustrasi** yang disusun ulang dari kode sumber WiFiManager 2.0.17, bukan tangkapan HP. Foto perangkat keras di folder ini (`foto-perfboard.jpg`, `foto-sambungan-solder.jpg`, `foto-terminal-ferrule.jpg`) berasal dari Wikimedia Commons karena penulis tidak memegang barangnya; foto-foto itu **mengikuti lisensi aslinya** (dicek per berkas di halaman berkasnya), bukan lisensi CC kurikulum, dan tidak ada yang dibuat dengan AI. Foto hanya dipotong, diubah ukurannya, dan dibuang metadatanya (EXIF, XMP, profil warna); dua potongan foto sambungan solder disusun berdampingan dan diberi penanda centang dan silang oleh penulis.
